8051 Digital Clock and Stopwatch

This project implements a digital clock and stopwatch using 8051 Assembly language.

Features

- Displays clock and stopwatch values.
- Allows switching between clock and stopwatch modes.
- Uses Timer 1 interrupts for timekeeping.
- Displays digits using a multiplexed display.

How It Works

The program reads user inputs to select the display mode and control the stopwatch. Timer 1 interrupts are used to update the clock and stopwatch, while the display routine shows the current values.
